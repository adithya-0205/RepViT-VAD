Project Overview

This project focuses on building a real-time Video Anomaly Detection (VAD) system capable of identifying abnormal events from video footage. My individual contribution within the team is to handle the Fighting anomaly category — detecting violent physical altercations in surveillance-like video clips.

The overall system is designed around the RepViT-M1.0 lightweight backbone combined with a Temporal Convolutional Network (TCN) for temporal modeling, and an anomaly scoring head that produces a single binary probability score. The trained model is further prepared for on-device INT8 deployment via ONNX export targeting a custom RISC-V AI Accelerator.

🏗
Model Architecture

The system pipeline processes an input video clip as a sequence of frames and outputs an anomaly score between 0 and 1.

Component Details Output Dimension
Input Video clip — (Batch, 16 Frames, 3, 224×224) —
Backbone RepViT-M1.0 (upgraded from M0.9) 448-dim per frame
Temporal Module TCN with 3 dilated TemporalBlocks (dilation: 1,2,4) 128-dim vector
Anomaly Head GAP → Linear(128→64) → ReLU → Dropout(0.3) → Linear(64→1) → Sigmoid Score ∈ [0.0, 1.0]
Quantization QAT via torch.ao.quantization (fbgemm backend) → INT8 —
Deployment ONNX Export (opset 14) → RISC-V NPU Accelerator repvit_m1_0_tcn_riscv.onnx

Work Completed This Week

The following tasks were completed during this reporting period:

  • Upgraded the RepViT backbone from M0.9 (384-dim) to M1.0 (448-dim) for better feature representation.
  • Updated the Temporal Convolutional Network (TCN) input dimensions accordingly from 384 to 448 channels.
  • Redesigned the classification head to a binary anomaly scoring head using Global Average Pooling + MLP + Sigmoid, replacing the old cross-entropy multi-class setup.
  • Integrated QuantStub and DeQuantStub into the model for Quantization-Aware Training (QAT) support.
  • Implemented a complete QAT training pipeline (qat_train.py) that prepares, trains, and converts the model to INT8 format.
  • Built and tested an ONNX export script (export_riscv_onnx.py) targeting the custom RISC-V AI Accelerator with opset version 14.
  • Fixed a loss function mismatch bug (CrossEntropyLoss → BCELoss) that caused an IndexError during training.
  • Completed 10-epoch training on the Fighting anomaly dataset, achieving 85% validation accuracy.
  • Pushed the complete codebase to GitHub: github.com/adithya-0205/RepViT-VAD.
  • Authored a professional README.md with setup instructions for teammates.
